
# 🚀 MediLocator — Smart Hospital Finder with Real-Time Availability

> **Find nearby hospitals instantly with real-time bed availability and smart filtering.**

---

## 🌐 Overview

**MediLocator** is a modern web application that helps users quickly locate nearby hospitals and check real-time bed availability. Designed with accessibility and speed in mind, it ensures users can make critical healthcare decisions efficiently.

The platform combines **interactive maps, real-time data, and intuitive UI** to deliver a seamless experience.

---

## ✨ Key Features

### 🔍 Smart Search
- Search hospitals by **name or city**
- Fast and responsive results

### 📡 Real-Time Bed Availability
- Live updates on hospital bed status
- Helps users make **time-sensitive decisions**

### 🎯 Advanced Filtering
- Filter hospitals based on:
  - Distance 📍  
  - Type 🏥  
  - Availability 🟢  

### 🔐 User Authentication
- Secure login & registration
- Personalized experience for users

### 🛠️ Admin Dashboard
- Manage hospital records
- Update bed availability in real-time
