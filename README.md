🚑 MediLocator – Smart Hospital Finder
🌐 Overview

MediLocator is a modern web application designed to help users quickly locate nearby hospitals and check real-time bed availability. Built with speed, accessibility, and usability in mind, it empowers users to make critical healthcare decisions instantly.

By combining interactive maps, live data, and an intuitive interface, MediLocator delivers a seamless and reliable experience during emergencies.

✨ Key Features
🔍 Smart Search
Search hospitals by name or city
Fast, real-time results with minimal latency
📡 Real-Time Bed Availability
Live updates on hospital bed status
Helps users make time-sensitive decisions
🎯 Advanced Filtering

Filter hospitals based on:

📍 Distance
🏥 Hospital Type
🟢 Availability Status
🔐 User Authentication
Secure login & registration
Personalized user experience
🛠️ Admin Dashboard
Manage hospital records
Update bed availability dynamically
Maintain accurate real-time data

🚀 Getting Started
1️⃣ Clone the Repository
git clone https://github.com/Robot1508/Medilocator.git
cd Medilocator
2️⃣ Install Dependencies
npm install
3️⃣ Setup Firebase
Go to Firebase Console
Create a new project
Add your configuration inside:
js/firebase-config.js
4️⃣ Run Locally
npx http-server
5️⃣ Open in Browser
http://localhost:8080
